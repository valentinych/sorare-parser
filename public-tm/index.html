    Идеальный пик

    По этапам от раннего к позднему: ставка менеджера ↓, максимум этапа ↓, средняя уникальных финальных ставок API ↓, стабильный ID. Идеальная ставка — максимум других fantasy-команд +1M; расчёты менеджеров независимы.

    «Кто перебил» сравнивает идеальные цели с историческим исходом при исходных ставках. Новую идеальную ставку исторически никто бы не перебил. «Перебил на этапе» и «Забрал позже» — разные исходы.

      Источник: видимые ленты Companion на sorare.com

      1. В Chrome открой страницу расширений, включи Developer mode и выбери Load unpacked: chrome://extensions
      2. Укажи папку этого репозитория: browser-import-helper
      3. Создай одноразовый код ниже.
      4. Открой страницу sorare.com, где Companion уже показал ленты, и вставь код в панель Mantra import.

      Данные обновляются только когда ты открываешь страницы Sorare и запускаешь импорт. Токены, cookies и пароли не читаются.
